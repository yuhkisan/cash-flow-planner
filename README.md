# Cash Flow Planner

個人の借金返済から事業の資金繰りまで、将来の入出金をもとに資金残高を予測するアプリ。

## 主な機能

- 現在残高の管理
- 単発・定期の入出金予定
- 借入条件から返済予定を自動生成
- 将来残高の予測
- 資金ショート予定日の表示
- シナリオ比較

## 技術構成

- React Router
- TypeScript
- NestJS
- PostgreSQL
- Docker

## 方針

個人の借金と法人融資を別物として扱わず、「将来の支払い義務」として共通化する。

MVPでは複式簿記や銀行連携は扱わず、まず「未来の現金が見える」ことを成立させる。
